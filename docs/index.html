Get started

Run easyHouse on your Mac

Scraping and listings stay on your machine. Verification emails are sent through the easyHouse cloud auth service — no SMTP setup required. 

git clone https://github.com/YOUR_USER/easyHouse.git
cd easyHouse
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/agent.py --open-browser

Then open http://127.0.0.1:8080/app, create an account, and enter the verification code from your email.
